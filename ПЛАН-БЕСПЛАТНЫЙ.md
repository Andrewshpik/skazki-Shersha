# Большой план развития «Сказки Шерша» — только бесплатное

> Цель: довести сайт до максимально качественного и завершённого вида, не используя платные сервисы и подписки.
> Ограничение: всё реализуется на текущем стеке (static HTML/JS + Flask на free-хостинге + Supabase free).

## Уже сделано (база)
- БД Supabase, API на Flask, общая лента, вход/регистрация/гость/Telegram.
- Безопасность: rate limiting, фильтр мата, валидация, XSS-экранирование.
- Supabase Storage для картинок; смена/восстановление пароля; теги; сортировка.
- Модерация: жалобы, баны (админ); роль админа.
- Уведомления (колокольчик), PWA, lazy-load, индексы БД.
- SEO: sitemap, robots, JSON-LD, Open Graph; страницы «О проекте», «Правила»; футер; «Случайная сказка»; 5 тем.

## Блок 11. Озвучка: как сделать лучше (отложено, решение автора — «пока ничего»)

Сейчас: `player.js` на Web Speech API, голоса берутся из системы (на Windows 11 — Ирина/Павел, дефолт женский, выбор запоминается). Качество = качество системных голосов.

- [x] **Запись своим голосом — инфраструктура готова.** Поле `audio` у поста, `POST /api/audio` (mp3/m4a/ogg/wav до 15 МБ в Storage), в форме поста «Озвучка автора», плеер играет файл вместо синтеза (с паузой, скоростью и таймером сна). Осталось только записать сами сказки и прикрепить файл.
- [x] **Улучшить текущий синтез.** Сделано: паузы 0,6 с на границе абзацев, мягкая скорость по умолчанию 0,95× (0,8 / 0,95 / 1,15 / 1,4), таймер сна 15/30/60 мин, показ текущей фразы в плеере. Качество самого голоса не меняет — это следующий пункт.
- [ ] **Своя нейросеть на сервере.** Piper (MIT, лёгкие модели) или Silero TTS (torch, тяжелее) на Flask, отдача mp3. Плюсы: живой голос, без внешних сервисов. Минусы: надо проверить, потянет ли бесплатный контейнер Netrun (память/CPU, холодный старт), качество ниже записи.
- [ ] **Сервис озвучки с бесплатным лимитом.** Яндекс SpeechKit / Sber SaluteSpeech. Плюсы: лучшее качество синтеза на русском. Минусы: нужна регистрация, привязка карты и контроль лимита символов — не «совсем бесплатно».

Как выбрать: нужен максимум качества и есть время наговаривать — вариант 1; нужно «просто приятнее» без работы — вариант 2 (+ установить голоса Windows или слушать в Edge); нужен синтез без записи, но живее SAPI — вариант 3, начиная с замера ресурсов контейнера.
